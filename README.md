# ZimaClient

Zima client apps for macOS, Windows, and Android.

## Download

Get the latest builds from [Releases](https://github.com/IceWhaleTech/ZimaClient/releases/latest).

| Platform | File |
| --- | --- |
| macOS (arm64) | `Zima-*-mac-arm64.pkg` |
| Windows (x64) | `Zima-*-win-x64.exe` |
| Android | `Zima-*-android.apk` |

Verify downloads against the bundled `SHA256SUMS-*.txt` files.
